# Reference decisions

Inspected 17 October 2026. These sources informed implementation rather than being copied as application code.

- [Spicetify extension development](https://spicetify.app/docs/development/extensions/): extension deployment, readiness checks, Topbar button, PopupModal, local storage, apply workflow.
- [Spicetify Player API](https://spicetify.app/docs/development/api-wrapper/methods/player): `songchange`, `onplaypause`, `onprogress`, `getProgress()`, `getDuration()`, and `isPlaying()`.
- [Electron BrowserWindow](https://www.electronjs.org/docs/latest/api/browser-window): transparent frameless windows, always-on-top level, focusability, ignore-mouse-events, work-area geometry, background acrylic, isolated/sandboxed web preferences.
- [Lyrics Plus source](https://github.com/spicetify/cli/tree/main/CustomApps/lyrics-plus), specifically [Providers.js](https://raw.githubusercontent.com/spicetify/cli/main/CustomApps/lyrics-plus/Providers.js) and [ProviderLRCLIB.js](https://raw.githubusercontent.com/spicetify/cli/main/CustomApps/lyrics-plus/ProviderLRCLIB.js): confirmed that its Spotify lyrics provider calls an internal color-lyrics endpoint. This is not treated as a stable public API and is not implemented. No credentials, scraping, interception, or unauthorized extraction from other extensions occurs. LRCLIB is independently integrated through documented endpoints. An optional Lyrics Plus adapter remains unsupported because no stable, authorized external bridge contract was established.
- [LRCLIB API documentation](https://lrclib.net/docs) and [upstream repository](https://github.com/tranxuanthang/lrclib): documented public lookup/search; no API key requested. Network availability was checked against the public search endpoint. Public accessibility does not grant redistribution rights to the lyric text. The project does not bundle provider lyrics.
- [W3C TTML2](https://www.w3.org/TR/ttml2/): the supported timing subset and explicit rejection of unsupported constructs are documented in README. Absolute music-export mode is a compatibility option, not a change to W3C relative timing semantics.
- [Gemini generateContent REST reference](https://ai.google.dev/api/generate-content) and [text generation](https://ai.google.dev/gemini-api/docs/text-generation): contextual translation requests, API-key header, system instruction and JSON response configuration. The configured model remains user selectable.
- [Ollama generate API](https://docs.ollama.com/api/generate): local non-streamed JSON generation using an already installed model. [MyMemory API](https://mymemory.translated.net/doc/spec.php) is a basic keyless alternative; its real public endpoint was checked with a short non-lyrical phrase. No universal translation-quality claim is made.
- [Developer portfolio](https://xtufa7.github.io/): verified public developer name, handle and links to GitHub, X, Instagram and email for the in-app About screen.
- Bundled [Inter](https://www.npmjs.com/package/@fontsource/inter), [Cairo](https://www.npmjs.com/package/@fontsource/cairo), [Noto Sans JP](https://www.npmjs.com/package/@fontsource/noto-sans-jp): offline font assets under SIL OFL. License texts are included in the build's `licenses/` directory.

Environment used: Windows build 26200 (Windows 11), Node 26.7.0, npm 11.19.0, Spicetify 2.45.3, Electron 44.9.0, electron-builder 26.15.3. The lockfile records exact dependency versions. `global-agent` is overridden to maintained version 4.1.3 within Electron download tooling to eliminate the vulnerable old sprintf dependency chain; runtime network traffic uses Node/Electron APIs, not that build helper.
